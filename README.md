# VALOVA — сайт тату-мастера с 3D-примерочной

Сайт для [@tattoo.by.valova](https://instagram.com/tattoo.by.valova).
Концепция — «Атлас кожи»: светлый бумажный сайт в нише, где почти все делают тёмный,
плюс 3D-примерочная, где любой эскиз можно посадить на тело.

- `docs/PROMPT.md` — промт-бриф: концепция, дизайн-система, структура.
- `docs/REFERENCES.md` — 15 изученных сайтов: что взяли и чего избегаем.

## Что внутри

| Блок | Что делает |
|---|---|
| Hero | Имя `VALOVA` с вариативной жирностью, которая меняется от курсора; «рис. 1» прорисовывается линией; курсор оставляет чернильный след |
| Манифест | Слова «прокрашиваются» чернилами при скролле |
| Каталог образцов | Работы с «паспортом» (№, стиль, зона, см, часы), фильтр, лайтбокс |
| **Примерочная 3D** | Фигура (она / он), 6 ракурсов, загрузка своего эскиза с автоудалением фона, перенос тапом, перетаскивание, размер в см, поворот, цвет / ч-б, свежая / зажившая, 7 тонов кожи, скачать фото, отправить мастеру |
| Флеш-лист | Свободные эскизы с ценой, кнопка «примерить» отправляет эскиз в 3D |
| Протокол сеанса | 5 шагов со sticky-цифрой |
| Памятка-чек | Уход после сеанса, «печатается» при скролле |
| Заявка | Собирает текст, копирует его, открывает Direct; прикладывает снимок из примерочной |

## Запуск

```bash
npm install
npm run dev           # разработка: http://localhost:5173
npm run build         # готовый сайт в dist/
npm start             # продакшен-сервер: отдаёт dist/ и принимает заявки (нужен .env)
npm run build:single  # весь сайт одним файлом dist-single/index.html
```

**Продакшен на своём VPS (домен, HTTPS, pm2, nginx) — пошагово в [DEPLOY.md](DEPLOY.md).**

`build:single` удобен, чтобы показать сайт без хостинга: файл открывается
двойным кликом в браузере, всё (шрифты, 3D-модель) уже внутри.

## Языки

Основной язык — **украинский**, второй — **английский** (переключатель UA / EN в шапке,
выбор запоминается; прямая ссылка на английскую версию — `?lang=en`).

- Украинский текст страницы написан прямо в `index.html`.
- Английский текст страницы — `src/i18n-page-en.js` (ключи совпадают с `data-i18n`).
- Тексты из JS (кнопки примерочной, заявка, подписи) — `src/i18n.js`.
- Данные работ и эскизов задаются парой `{ uk: '…', en: '…' }` в `src/data/`.

## Заявки в Telegram

Форма заявки отправляет сообщение (вместе со снимком из примерочной) на свой сервер
(`POST /api/booking`, `server/`), а он — в Telegram-бота. Токен бота хранится только
в `.env` на сервере; в коде сайта и в репозитории его нет и быть не должно.
Сборка с `VITE_BOOKING_ENDPOINT=` (пусто, как на GitHub Pages) вместо этого копирует
текст и открывает Direct.

## Мобильная примерочная

`tryon.html` — отдельная страница 3D-примерочной на весь экран: вкладки «Ескіз / Посадка /
Шкіра», крупные элементы под палец, зум щипком, заявка в выезжающей шторке.
На телефоне главная страница показывает вместо 3D кнопку, ведущую сюда; кнопки
«приміряти» во флеш-листе открывают эскиз сразу на этой странице (`tryon.html?design=moth`).

## Производительность 3D

- Кадр рисуется только когда что-то меняется (вращение, перенос тату, смена кожи);
  в покое GPU не работает — телефон не греется и не садится.
- Поиск точки касания на теле — через BVH-дерево (`three-mesh-bvh`): ~0,05 мс вместо ~8 мс
  на каждое движение пальца.
- На телефонах — тени 1024 px и плотность пикселей до 1.75.

## Иконка и превью ссылки

- `public/favicon.svg` (+ `favicon-32.png`, `apple-touch-icon.png`) — «искра» из флеш-листа.
- `public/og.jpg` — картинка-превью, когда ссылку кидают в Telegram / Instagram.
  Полные адреса в `og:*`, canonical, `sitemap.xml` и `robots.txt` подставляются при сборке
  из `VITE_SITE_URL` (в `.env`).

## Безопасность

- Content-Security-Policy: скрипты, стили, шрифты и запросы — только к самому сайту,
  никаких inline-обработчиков, `object-src 'none'`, `frame-ancestors 'none'`.
  Сервер дополнительно шлёт `X-Frame-Options`, `nosniff`, `Referrer-Policy`, `Permissions-Policy`;
  nginx — HSTS.
- Всё, что вводит посетитель (имя файла, текст заявки), выводится только как текст,
  без вставки HTML.
- Загрузка эскиза: только PNG / JPG / WEBP до 15 МБ, обработка целиком в браузере,
  файл никуда не отправляется.
- Приём заявок: только со своего сайта (Origin), лимит частоты в nginx и в сервере,
  ловушка для ботов, ограничения длины полей и размера тела (3 МБ), сообщения в Telegram
  без разметки, токен не пишется в логи.
- Сервер слушает только `127.0.0.1`, наружу его отдаёт nginx; выход за пределы `dist/` закрыт.
- `npm audit`: в зависимостях сайта уязвимостей нет; предупреждения относятся только
  к `vite-plugin-singlefile` (инструмент сборки, на сайт не попадает).

## Как заменить заглушки на реальные данные

1. **Фото работ** → положить в `public/works/` (например `01.jpg`), затем в
   `src/data/site.js` у работы указать `img: 'works/01.jpg'` (поле `flash` можно удалить).
2. **Свободные эскизы** → `src/data/flash.js`. Сейчас там 6 демо-эскизов, нарисованных кодом.
3. **Контакты, город, Telegram** → `src/data/site.js` (`site`).
4. **Цены** → `src/data/flash.js` (поле `price`).

## 3D-модель

Тело — базовый меш [MakeHuman](https://github.com/makehumancommunity/makehuman)
(лицензия **CC0**, можно использовать свободно, в том числе коммерчески).
Он упакован в `src/tryon/body.bin` (~320 КБ) скриптом `tools/build-body.mjs`
и сглаживается в браузере подразделением Loop. Пересобрать модель:

```bash
git clone --depth 1 --filter=blob:none --sparse https://github.com/makehumancommunity/makehuman.git mh
(cd mh && git sparse-checkout set makehuman/data/3dobjs makehuman/data/targets/macrodetails)
node tools/build-body.mjs mh/makehuman/data
```

## Технологии

Vite, ванильный JS, three.js (`DecalGeometry` + `MultiplyBlending` — чернила
«ложатся в кожу»), GSAP + ScrollTrigger, Lenis. Шрифты с кириллицей подключены
локально через `@fontsource`: Unbounded, Cormorant Garamond, Caveat, JetBrains Mono.
3D-модуль загружается лениво — только когда посетитель доскроллил до примерочной.
