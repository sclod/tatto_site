# VALOVA — сайт тату-мастера с 3D-примерочной

Сайт для [@tattoo.by.valova](https://instagram.com/tattoo.by.valova).
Концепция — «Атлас кожи»: светлый бумажный сайт в нише, где почти все делают тёмный,
плюс 3D-примерочная, где любой эскиз можно посадить на тело.

- `docs/PROMPT.md` — промт-бриф: концепция, дизайн-система, структура.
- `docs/REFERENCES.md` — 15 изученных сайтов: что взяли и чего избегаем.

## Что внутри

| Блок | Что делает |
|---|---|
| Hero | Имя `VALOVA` с вариативной жирностью, которая меняется от курсора; «рис. 1» прорисовывается линией; курсор оставляет чернильный след |
| Манифест | Слова «прокрашиваются» чернилами при скролле |
| Каталог образцов | Работы с «паспортом» (№, стиль, зона, см, часы), фильтр, лайтбокс |
| **Примерочная 3D** | Фигура (она / он), 6 ракурсов, загрузка своего эскиза с автоудалением фона, перенос тапом, перетаскивание, размер в см, поворот, цвет / ч-б, свежая / зажившая, 7 тонов кожи, скачать фото, отправить мастеру |
| Флеш-лист | Свободные эскизы с ценой, кнопка «примерить» отправляет эскиз в 3D |
| Протокол сеанса | 5 шагов со sticky-цифрой |
| Памятка-чек | Уход после сеанса, «печатается» при скролле |
| Заявка | Собирает текст, копирует его, открывает Direct; прикладывает снимок из примерочной |

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # готовый сайт в dist/
npm run build:single  # весь сайт одним файлом dist-single/index.html
```

`build:single` удобен, чтобы показать сайт без хостинга: файл открывается
двойным кликом в браузере, всё (шрифты, 3D-модель) уже внутри.

## Как заменить заглушки на реальные данные

1. **Фото работ** → положить в `public/works/` (например `01.jpg`), затем в
   `src/data/site.js` у работы указать `img: 'works/01.jpg'` (поле `flash` можно удалить).
2. **Свободные эскизы** → `src/data/flash.js`. Сейчас там 6 демо-эскизов, нарисованных кодом.
3. **Контакты, город, Telegram** → `src/data/site.js` (`site`).
4. **Цены** → `src/data/flash.js` (поле `price`).

## Публикация (GitHub Pages)

В репозитории уже есть `.github/workflows/deploy.yml`. Достаточно:

1. Settings → Pages → Source: **GitHub Actions**.
2. Влить изменения в ветку `main` — сайт соберётся и опубликуется сам.

Сайт статический, его можно выложить на любой хостинг (Netlify, Vercel, обычный сервер) —
просто загрузить папку `dist/`.

## 3D-модель

Тело — базовый меш [MakeHuman](https://github.com/makehumancommunity/makehuman)
(лицензия **CC0**, можно использовать свободно, в том числе коммерчески).
Он упакован в `src/tryon/body.bin` (~320 КБ) скриптом `tools/build-body.mjs`
и сглаживается в браузере подразделением Loop. Пересобрать модель:

```bash
git clone --depth 1 --filter=blob:none --sparse https://github.com/makehumancommunity/makehuman.git mh
(cd mh && git sparse-checkout set makehuman/data/3dobjs makehuman/data/targets/macrodetails)
node tools/build-body.mjs mh/makehuman/data
```

## Технологии

Vite, ванильный JS, three.js (`DecalGeometry` + `MultiplyBlending` — чернила
«ложатся в кожу»), GSAP + ScrollTrigger, Lenis. Шрифты с кириллицей подключены
локально через `@fontsource`: Unbounded, Cormorant Garamond, Caveat, JetBrains Mono.
3D-модуль загружается лениво — только когда посетитель доскроллил до примерочной.
