# Промт-бриф: сайт тату-мастера VALOVA

> Этот текст — промт, который я (Claude) составил сам себе перед тем, как писать код.
> Его можно переиспользовать для следующих итераций: «прочитай docs/PROMPT.md и доделай X».

## Роль

Ты — арт-директор и креативный фронтенд-разработчик уровня Awwwards/FWA.
Делаешь сайт-портфолио для тату-мастера **@tattoo.by.valova**. Сайт должен продавать
запись на сеанс и запоминаться с первого экрана.

## Главная проблема рынка

98 % тату-сайтов выглядят одинаково: чёрный фон, черепа, готический шрифт или
золотая антиква, сетка 3×3 из фото из Инстаграма, кнопка «записаться».
Даже сайты-победители Awwwards (Monolith, Flatbone, Mysta Electric) — тёмные и
«брутальные». Задача: **отличаться минимум на 60 %** от этого шаблона.

## Концепция: «Атлас кожи» (Skin Atlas)

Сайт — это не витрина салона, а **анатомический атлас / каталог образцов**,
как старинные научные издания: тёплая бумага, гравюрные подписи, номера образцов,
пометки от руки на полях. Татуировки — «экспонаты» с паспортом
(№, зона, размер, часы работы). 3D-примерочная — это «гипсовая скульптура»
из художественной академии, на которую можно «нанести» свой эскиз.

Почему цепляет:
1. **Светлый, бумажный сайт** в нише, где все делают тёмный.
2. **Примерочная в 3D** вместо статичной галереи — человек уходит с картинкой
   «как это будет на мне» и сразу отправляет её мастеру.
3. **Типографика как характер**: четыре шрифта, у каждого своя роль.
4. **Живые детали**: курсор оставляет чернильный след, буквы имени «набухают»
   от приближения курсора, памятка по уходу печатается как чек.

## Дизайн-система

| Токен | Значение | Роль |
|---|---|---|
| `--paper` | `#EEE8DC` | фон, тёплая бумага с шумом |
| `--paper-2` | `#E4DCCB` | карточки, подложки |
| `--ink` | `#16151B` | основной текст, «чернила» |
| `--ink-soft` | `#6B665E` | вторичный текст |
| `--flash` | `#D23A1E` | акцент: «флеш-красный» классических эскизов |
| `--vein` | `#2F4A6B` | редкий второй акцент: синие пометки |

**Шрифты (все с кириллицей, self-hosted через @fontsource):**
- **Unbounded Variable** — огромные заголовки, имя. Вариативная жирность
  анимируется курсором.
- **Cormorant Garamond Italic** — поэтические акцентные слова внутри заголовков.
- **Caveat** — рукописные пометки на полях, стрелки, цены во флешах.
- **JetBrains Mono** — «паспорта» образцов, навигация, служебные подписи.

**Правила:**
- Ни одного черепа, розы-клише или готического шрифта.
- Много воздуха, асимметричная сетка, текст может «залезать» на изображения.
- Пометки от руки — не больше 1–2 на экран, иначе станет «скрапбуком».
- `prefers-reduced-motion` выключает тяжёлую анимацию и чернильный след.

## Структура страницы

1. **Прелоадер** — «заправляем машинку», счётчик 0–100.
2. **Hero** — гигантское `VALOVA`, вариативный вес букв от курсора, крутящийся
   штамп «запись открыта», чернильный след за курсором.
3. **Манифест** — крупный текст, слова «прокрашиваются» чернилами при скролле,
   внутри строк — маленькие капсулы с фото работ.
4. **Каталог образцов** (галерея) — асимметричная сетка, у каждой работы паспорт,
   фильтр по стилям, лайтбокс.
5. **Примерочная (3D)** — фигура-скульптура (она / он) на постаменте,
   быстрые ракурсы: целиком, рука, спина, грудь, нога, шея.
   - загрузка своего эскиза (PNG/JPG), автоудаление бумажного фона;
   - нажатие на тело — перенести тату, перетаскивание — подвинуть;
   - тату сама выравнивается вдоль руки/ноги;
   - размер в сантиметрах, поворот, цвет/ч-б, «свежая» / «зажившая»;
   - 6 тонов кожи + «гипс»;
   - скачать PNG и «отправить мастеру» (скрин сразу прикрепляется к заявке).
6. **Свободные эскизы (флеши)** — горизонтальная лента листов с ценой от руки,
   у каждого кнопка «примерить» → эскиз сразу улетает в 3D-примерочную.
7. **Протокол сеанса** — 5 шагов со sticky-цифрой.
8. **Памятка по уходу** — «чек», который печатается при скролле.
9. **Заявка** — форма, которая собирает сообщение и открывает Direct/Telegram.
10. **Футер** — бегущая строка «НАВСЕГДА —», ссылки.

## Технологии

- Vite + ванильный JS (без фреймворка — быстрее и проще деплой).
- three.js: тело — базовый меш MakeHuman (CC0), упакованный в 320 КБ и
  сглаженный подразделением Loop в браузере; `DecalGeometry` для проекции тату
  на связный участок кожи, `MultiplyBlending` чтобы чернила «ложились в кожу»,
  а не висели наклейкой.
- GSAP + ScrollTrigger + Lenis — скролл-анимации и плавный скролл.
- 3D-модуль грузится лениво, только когда пользователь доскроллил до примерочной.
- Деплой: GitHub Pages через Actions (`.github/workflows/deploy.yml`).

## Что нужно от заказчика

- 12–30 фото работ (лучше квадрат/вертикаль, хорошим светом) → `public/works/`.
- 4–8 свободных эскизов (PNG на белом/прозрачном) → `public/flash/`.
- Имя, город, адрес студии, Telegram/WhatsApp, цены «от».
- Фото мастера (по желанию) для блока «о себе».
