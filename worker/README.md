# Заявки с сайта → Telegram

Сайт статический (GitHub Pages), поэтому токен бота нельзя класть ни в код сайта,
ни в репозиторий — его увидит любой. Заявки идут через маленький сервер
**Cloudflare Worker** (бесплатно), где токен хранится как секрет.

## 1. Узнать CHAT_ID

1. Напиши своему боту в Telegram любое сообщение (например `/start`).
   Если заявки должны приходить в группу — добавь бота в группу и напиши там.
2. Открой в браузере `https://api.telegram.org/bot<ТОКЕН>/getUpdates`
   (вместо `<ТОКЕН>` — токен бота).
3. Найди `"chat":{"id": 123456789 ...}` — это число и есть `CHAT_ID`
   (у групп оно отрицательное, с минусом).

## 2. Создать воркер (без командной строки)

1. Зарегистрируйся на https://dash.cloudflare.com → **Workers & Pages** → **Create** →
   **Create Worker** → назови `valova-booking` → **Deploy**.
2. **Edit code** → удали всё → вставь содержимое `booking-worker.js` → **Deploy**.
3. **Settings → Variables and Secrets**:
   - `BOT_TOKEN` — тип **Secret**, значение — токен бота;
   - `CHAT_ID` — тип **Secret**, значение из шага 1;
   - `ALLOWED_ORIGIN` — тип **Text**, значение `https://sclod.github.io`.
4. Скопируй адрес воркера, вида `https://valova-booking.<имя>.workers.dev`.

## 3. Подключить к сайту

В `src/data/site.js` впиши адрес в `bookingEndpoint`:

```js
bookingEndpoint: 'https://valova-booking.<имя>.workers.dev',
```

Пока поле пустое, форма работает по-старому: копирует текст и открывает Direct.

## Что защищено

- токен только в секретах воркера;
- заявки принимаются только с адреса сайта (`ALLOWED_ORIGIN`);
- лимит частоты запросов с одного IP, скрытое поле-ловушка и проверка времени заполнения против ботов;
- длина всех полей и размер фото ограничены, текст уходит в Telegram без разметки.

Если токен когда-либо светился публично (в чате, в коде) — перевыпусти его:
@BotFather → `/mybots` → бот → **API Token** → **Revoke current token**,
и вставь новый в секрет `BOT_TOKEN`.
